# Nuvera — tjekliste før live

> ⚠️ Ikke juridisk rådgivning. Få det bekræftet hos revisor/advokat. Listen samler de punkter, vi er stødt på undervejs.

## 1. Selskab & navn
- [ ] Reservér/registrér **Nuvera ApS** på [virk.dk](https://datacvr.virk.dk) (CVR, branchekode for detailhandel med kosttilskud)
- [ ] Bekræft at navnet er tilstrækkeligt adskilt fra eksisterende selskaber (fx Nuvera Sports ApS, Herning)
- [ ] Sikr domæne **nuvera.dk** (bekræftet ledigt) + relevante varianter
- [ ] Overvej varemærkeregistrering hos Patent- og Varemærkestyrelsen; tjek "Nuvera" mod eksisterende varemærker (DK/EU)

## 2. Moms & adskillelse fra Aevia
- [ ] Moms-registrér Nuvera (kosttilskud = **25 % moms** på varer)
- [ ] Hold aktiviteten **adskilt** fra Aevias momsfrie sundhedsydelser — egen drift, egen faktura, eget checkout
- [ ] **Ingen bundling** af helbredstjek + tilskud i én samlet faktura
- [ ] Armslængde mellem selskaberne (markedspris ved evt. ydelser imellem dem; interesseforbundne parter)
- [ ] Hvis Aevia formidler/henviser mod vederlag: struktureres og beskattes korrekt (momspligtig formidling)

## 3. Habilitet & transparens (sundhedspersoner)
- [ ] Aevias anbefalinger skal være **klinisk begrundede**, ikke salgsdrevne
- [ ] Ejerforholdet mellem Aevia og Nuvera **oplyses tydeligt** (undgå skjult reklame, markedsføringsloven)
- [ ] Helst **generisk** anbefaling ("du bør supplere med D-vitamin") frem for "køb vores"
- [ ] Nuvera er **én mulighed** kunden frit kan vælge

## 4. GDPR (helbredsdata)
- [ ] Markører hentes fra Aevia **kun med udtrykkeligt samtykke** (art. 9, følsomme data)
- [ ] **Databehandleraftale** mellem Aevia og Nuvera
- [ ] Samtykke kan trækkes tilbage; sletning; indsigt; dataminimering (kun relevante markører)
- [ ] Privatlivspolitik + cookie-samtykke på sitet

## 5. Kosttilskud — fødevareregler
- [ ] **Notifikation til Fødevarestyrelsen** for hvert kosttilskud før salg
- [ ] Doser inden for tilladte maksimumgrænser (fx vitamin D, zink, jern)
- [ ] Korrekt **mærkning**: ingrediensliste, doser, anbefalet daglig dosis, "overskrid ikke", "ikke erstatning for varieret kost", "opbevares utilgængeligt for børn", allergener
- [ ] Jern kun ved dokumenteret behov; advarsler ved relevante stoffer

## 6. Sundhedsanprisninger (markedsføring)
- [ ] Alle "hvorfor"-tekster på siden + i mails renses gennem **EU-forordning 1924/2006** (kun godkendte anprisninger)
- [ ] **Ingen** påstande om at forebygge, behandle eller helbrede sygdom
- [ ] Før/efter-cases markeres som eksempler; ingen garanterede resultater

## 7. Produkt & kvalitet
- [ ] **GMP-certificeret** producent i EU
- [ ] **COA (analysecertifikat) pr. batch** — renhed, tungmetaller, mikrobiologi, oxidation (omega-3)
- [ ] Produktansvarsforsikring
- [ ] Omega-3 og probiotika leveres som separat kapsel (ikke i vand-pulver)

## 8. E-handel & abonnement
- [ ] Handelsbetingelser, abonnementsvilkår (opsigelse, pause, fornyelse)
- [ ] **Fortrydelsesret** (14 dage; vær opmærksom på undtagelse for forseglede sundhedsvarer brudt forsegling)
- [ ] Priser vist **inkl. moms**; tydelig løbende abonnementspris
- [ ] Betalingsløsning, leverings- og returbetingelser

## 9. Bevidst udeladt indtil afklaring
- [ ] Rød gæret ris (monacolin K) — lægemiddel-lignende, reguleret
- [ ] Melatonin — lægemiddel i DK
- [ ] NMN — uafklaret EU-fødevarestatus
